# Augment

## Guidelines / rules

Use reusable guidance for stable project conventions: architecture, code style, repository workflows, testing, and boundaries.

Official guidelines: https://docs.augmentcode.com/setup-augment/guidelines

## Apply rules selectively

Where supported, distinguish universal rules from specialized guidance that can be requested only when relevant:

```text
Always apply:
  small set of universal repository rules

Agent-requested:
  specialized guidance for specific tasks
```

This avoids loading specialized instructions into every task.

Official CLI rules: https://docs.augmentcode.com/cli/rules

## Checklist

- [ ] Are universal rules truly universal?
- [ ] Can specialized rules be requested only when needed?
- [ ] Is task scope explicit?
- [ ] Are tool outputs focused?
- [ ] Is verification part of the request?
